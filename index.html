NO LOCAL GPU NEEDED

Launch on Google Colab

The included notebook installs the backend, prepares an open model, and creates a temporary secure tunnel.

  1. 1
    Open the notebook

    Open Herogod_Colab.ipynb in Google Colab. Choose Runtime → Change runtime type → T4 GPU for lightweight models. FLUX 3, FIBO 2, and Qwen need substantially more GPU/RAM; free T4 is not sufficient for every option.

  2. 2
    Run the cells in order

    Keep the default InstructPix2Pix model for the easiest T4 setup. The first model download can take several minutes.

  3. 3
    Copy both connection values

    The launcher prints a https://…trycloudflare.com URL and a random Herogod access token. The tunnel is temporary and public, so keep the token private.

  4. 4
    Connect this interface

    Paste both values into Connection settings, test the connection, then save. You can use this opened HTML file or a hosted copy.

Closing or resetting the Colab runtime stops your backend and invalidates the tunnel. Generated images are returned to the browser; Herogod adds no server-side chat or image database.

Hugging Face

For hosted inference and gated Colab model downloads

  1. Create a free Hugging Face account and your own access token. Use read access for local downloads; hosted inference also needs Inference Providers permission.
  2. For FLUX 3 or FIBO 2, open the model page and accept its license conditions while logged in.
  3. Paste the token in Connection settings → Your HF token for this tab, or set HF_TOKEN through Colab Secrets/backend environment for a shared runtime.
  4. Select a Local / Colab model to download weights, or an HF Inference option to use available hosted credits. Provider deployment and quotas vary.

Google AI Studio

For Gemini image understanding and editing

  1. Open Google AI Studio and create an API key in an eligible region.
  2. Confirm that your chosen image model currently offers a free tier and review its limits.
  3. Set GEMINI_API_KEY on the backend. Optionally override GEMINI_MODEL.
  4. Select Gemini Flash Image in the composer. Provider safety filters are not bypassed.

Herogod has no built-in paid provider and does not include shared keys. “Free tier” refers to the provider’s own current offering; always check its official pricing page.
