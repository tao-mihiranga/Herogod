How to use Herogod

  1. Add a base image. Drop a file, paste, or pick one. The base image defines the scene and composition.
  2. Write the instruction. Say what should change and what should stay: “swap the jacket for a leather one, keep the face”.
  3. Add references (optional). Up to three extra images guide a subject, garment, or look.
  4. Pick a style. Styles append a fixed prompt fragment, exactly as shown in the chips' tooltips.
  5. Generate. Press Ctrl/⌘ + Enter. Press Stop to cancel.
  6. Iterate. Use as input feeds the result back in; the seed is kept for small variations.

Hardware reality check

Qwen-Image-Edit-2511 is a large model. A 16 GB GPU with bf16 works at reduced resolution; a T4 (16 GB) needs fp16 and patience; 4-bit quantisation lowers VRAM further. CPU-only runs are possible but very slow.

Privacy

There is no cloud moderation layer, no prompt log and no server-side image history. Images live in RAM until the runtime stops and are only downloaded when you press Save PNG. A temporary Colab tunnel URL is public, so keep the access token on.
